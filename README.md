# Advocacia Jônatas

Site institucional estático da Advocacia Jônatas, em Sorocaba/SP.

## Arquivos principais

- `index.html`: página inicial do site.
- `previdenciario.html`, `civil.html` e `trabalhista.html`: páginas das áreas de atuação.
- `historia.html`: história do escritório.
- `escritorio.html`: valores e forma de atendimento.
- `style.css`: estilos compartilhados pelas páginas.

Para editar o site, altere o HTML da página desejada e o CSS em `style.css`. O site não usa JavaScript.
